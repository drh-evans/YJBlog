# YJBlog - A football blog for football partisans.

YJBlog is a football themed blog allowing users to sign-up and discuss their favourite football topics.

## HOW TO RUN!

In order to run the web app you must run `Sail up -d`, you must ensure that Sail is installed and that Docker is open.

You MUST then run `sail npm run dev` to render the tailwindcss failure to do this will not run the css and the website will look rather... bland.
